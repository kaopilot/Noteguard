# Brief part — B1 Engine (check engine, differencing, bubbles, summary)

**What it is.** A pure Python package (`noteguard/engine/`) implementing the frozen `EngineAPI`: no web, file, network, clock or logging imports (`test_engine_is_pure`). Eight rules are built (CRIT-001, ALG-001, DOSE-001, DOSE-002, PEND-001, PDF-001, DIFF-001, OWN-001), each a pure function over the in-scope sources at a stated cutoff. All vocabulary (drugs, allergens, analytes, denials, frequencies, cues, thresholds) comes from the versioned registry (`test_single_term_registry`); thresholds are placeholders pending clinical governance.

**Deterministic path.** Statement spans in original code points → normalisation with an offset map → registry matching with a NegEx-style negation/uncertainty scope (uncertain → `review_required`, never a negative) → differencing (`carried_forward`, `explicit_change`, `reworded`, `new`) → rules → flag orchestration (stable identity, one disagreement = one flag, owner routing, rerun merge) → question bubbles → one-page summary where every claim is a template over flag/decision/bubble records with evidence.

**Challenged assumptions, as built.** Carried-forward text cannot suppress a critical flag. Suppression happens only at evaluation time; a flag a human could see is *superseded*, never resolved, and a superseded Tier 1 still blocks closure. "Not documented" is an `AbsenceFinding` that cannot be constructed while any in-scope source is unread; it becomes `incomplete_extraction` naming the source. A dose the checker cannot attach to a regimen is never a pass (DOSE-002).

**Measured (22 Sep 2026, session B1.1).**
- Golden fixtures: 5 of 5 scenarios match by exact set equality (flags, bubbles, summary claims, run); `make test-engine` 37 passed, 1 skipped (held-out ENC-A2 not given to B1).
- Determinism: two runs of each scenario give byte-identical JSON for run result, bubbles and summary.
- Latency: `run_checks` + `answer_bubbles` + `build_summary` on ENC-A1 at 16:00 (10 sources, 20 assertions, 5 flags, 7 bubbles): median 27.2 ms, p95 35.7 ms over 200 runs after 5 warm-ups; one process, Python 3.12.3, x86_64, 1 vCPU, in-memory fixtures, timed with `time.perf_counter` outside the engine.
- Mutation spot-checks: 25 applied; 22 caught; the 3 initially uncaught were two weak mutations (re-run with the intended mutation: caught) and one test gap in L2 (test strengthened; now caught).

**Where it fails first.** Regex/dictionary extraction misses paraphrase and terms outside the registry. The negation window is shallow (clause, 6 tokens). A response written in the same note as a critical value does not suppress (strict reading of 8.5; a false positive). PEND-001 associates subject and cue per statement (false positives). No maximum-dose screen. No OCR. Engine tests were written by the same lane as the engine; the independent checks are the @k-signed goldens and the held-out ENC-A2 at I1.
