# Brief part — B4 Governance and the AI line (measured 23 Sep 2026)

**Nothing learns online.** Feedback is recorded without content and read only by offline tools. The runtime loads a ruleset only if its approval record is approved, cites an evaluation report, and matches the file hashes, re-checked on every load; otherwise check runs return 503 `ruleset_unapproved`. v1 is a draft today; @k approves at CP2. `propose.py` refuses any proposal that lowers, disables, narrows or retires a protected rule (Tier 1, allergy, medication, critical-result, PDF). Rollback = re-pin the previous approved version.

**Release gate (measured).** The real engine over 23 gated cases (18 hand-labelled by B4 before the engine ran on them, fictional roster; 5 golden scenarios): **Tier 1 recall 17/17**, gate passed. B4 cases: 14/14 labelled flags raised; one declared false positive (CRIT-001 precision 4/5: a response phrased outside the registry, so the flag stays). The gate refuses a candidate that disables CRIT-001, lowers ALG-001 to Tier 2, or extends a negation cue. One evaluation took 0.10 s (single run, build container). Limits: the cases use registry vocabulary, so they test roster and wording, not paraphrase; golden cases are not independent.

**Exposure bias.** Feedback exists only for surfaced flags, so its rates say nothing about concerns never raised. Built: protected rules cannot be demoted; every rate names its denominator. Not built: a blind sample of non-flagged sources, dismissal-spike monitoring, learned (shadow) ranking.

**Aggregate view.** Counts by rule, tier, state and age; no text or identifiers; counts below 5 shown as "<5"; aggregate roles only, checked at route and store. Gaps: no complementary suppression; owner response time awaits CCR-04.

**AI line.** Off by default; the app is fully functional without it. When enabled it may only draft an explanation of one existing flag from its verified quotes, sent redacted. The draft is discarded for the rule text on any extra field (so no tier, owner or state), missing citation, entity or dose absent from the cited quotes, raised certainty, unsupported negation or forbidden phrase; a timeout or provider error shows "AI drafting unavailable; showing rule explanation". No route calls it yet. Limit: it recognises only registry entities.

**Evidence:** `make test-governance` 9 passed; 14 mutations applied, 14 caught.
