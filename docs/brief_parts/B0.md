# B0 — contracts, fixtures and test scaffold (brief part)

Every shared concept is defined once in `noteguard/contracts/` (enums, Section 7 entities, ids,
state machine, permission matrix as data, error codes, routes, log allowlist, forbidden phrases,
statement spans, egress gate). A seam test fails the build if any other module or the frontend
redefines one of them, which targets the care-core defect where two components each held drug
knowledge and disagreed.

Golden expectations for the synthetic encounter are hand-written from the rule catalog, not
generated by an engine, and compared by exact set equality; they list the clinically important
negatives explicitly (no dose flag on an explicit metformin change, no critical flag once the
15:30 response exists, no suppression from earlier, carried-forward or negated "reviewed" lines).
A held-out encounter with different names, drugs and phrasing is kept outside the repo and run
only at integration, to catch an engine tuned to the seed case.

Measured (executed, 22 Sep, `make test`): 24 B0 contract tests pass; 50 skeleton tests fail with
"not implemented" (lanes not landed); 0 real failures, 0 errors; 1 skipped (held-out, by design).
Four spot-check mutations (duplicate role list, forbidden phrase in a rule template, count
drift in one view, stale generated types) each made the relevant test fail.

Known gaps: goldens are signed off by one person (@kaopilot), and ENC-C1 and the held-out case are
not yet reviewed; the span convention mis-splits abbreviations; thresholds are
placeholders; the stub API enforces no authorisation and must not be demonstrated as the product.
