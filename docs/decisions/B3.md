3. **Known dev-only advisory: GHSA-82fw-gwwq-j7x9 (moderate) in vitest ≤ 4.1.10.** It is a path traversal via `vi.mock` redirect, reachable only when running untrusted test code; none of our tests use mock redirects.

5. **Unit tests live in `frontend/tests/`, outside `frontend/src`.** The seam scanner's per-line vocabulary check targets product source; tests legitimately name wire values.
   - The API double (`tests/fakeApi.ts`) is built from the golden fixtures and the contract route templates.
   - It picks the golden by (cutoff, prior scenario), so 11:30 then 16:00 serves `ENC-A1_1600_rerun`, matching the real API.
6. **"Decided" flags sit behind the history toggle**, derived from contract data rather than a hand-written state list: a state is decided when `CONTRACT.decisions.transitions` offers no move from it.
   - Every open or blocking count on screen is a server number (glance, closure view); the UI does no arithmetic on flag states.
7. **`! contradicts` chips** come from contradiction-lens flags' evidence, because `ChangeKind` has no "contradicts" value. Everything else in the chips is the run's `changes`.
8. **Display wording** uses `Record<WireType, string>` maps (labels.ts), so TypeScript fails the build if the contract adds a value. The maps choose words only.
9. **Permissions are hide-only.** Offered actions come from `CONTRACT.permissions` (role × tier × relation) plus `CONTRACT.decisions.transitions`. Relations are derived client-side for hiding only; the server re-checks at the route and store layers, and the UI shows its 403 text.
10. **Service worker is hand-written** (public/sw.js):
    - Precaches only the explicit build list (hashed assets, offline page, manifest, icons) injected by a 20-line Vite plugin.
    - No runtime caching at all (no `cache.put`).
    - `/api/`, non-GET and cross-origin requests are not intercepted.
    - Navigations are network-first, falling back to `offline.html`.
    - Registered only in production builds.
11. **A span whose converted slice does not equal `quote` is not highlighted;** the viewer says so. Showing the wrong words is worse than none.
12. **`StaleRevision` (409 body) is missing from the generated types.** It is read through a local structural type with optional fields typed by generated enums; CCR-03 is proposed.
13. **Closure "Check closure now" on 200** says no Tier 1 blocks closure and that closing in the EMR remains the clinician's action. Nothing is written back.
14. **The Playwright walk (`npm run e2e`) is not part of `make test`,** because it needs a browser and two servers.
    - `NG_CHROMIUM` only selects a local browser binary; it is not a security switch, so L12 is not engaged.
    - Its results are recorded in the handoff.
15. **`tests/ui/test_ui_placeholders.py` is replaced by `tests/ui/test_ui_frontend.py`:**

### Add-source UI and follow-ups (same session, after @k's review on 23 Sep)
27. **@k decided the add-source UI belongs to B3; running the UI (a make target or README step) goes to B5.**
    - Built: paste a note or upload a PDF, as a new source or a new version of an existing one.
    - New versions lock title, author, discipline and time to the original, and never send `identifier_namespace`. B2 refuses a namespace that differs from the source's, and the fixture sources use `urn:synthetic:fixture-emr`.
    - The author list shows care-team members only (the server refuses others).
    - One idempotency key per intended submission: a retry after a dropped connection reuses it, and any edit issues a new one. Keys come from `crypto.getRandomValues`, so plain-HTTP LAN addresses work.
    - Every refusal code has a plain sentence. A timed-out PDF is reported as kept and labelled incomplete.
    - No client-side size or page limits: they are B2 settings, not contract, so the server's answer is shown instead.
28. **Bug found while verifying intake with the real engine: the run control's default cutoff excluded a just-added note.**
    - The default was the latest recording time floored to the minute. B2 stamps `version_time` with sub-second server time, and a version is in scope only if `version_time <= cutoff`.
    - Rounding up to the minute is also wrong, because B2 refuses future cutoffs (422).
    - Fix: a seconds-capable input, defaulting to the latest recording time rounded **up to the second**. It is built from server timestamps (no client clock) and compared as instants.
    - Evidence with B1's engine through the UI: the added "Amlodipine 10 mg" note gets a "≈ reworded" chip and is cited by DOSE-001. An added potassium 6.8 gets "+ new" and CRIT-001.
    - My first Vitest case asserted the formatting ("equals the minute") and so encoded the bug. It now asserts the property (cutoff ≥ recording time, < 1 s later), and the old behaviour is a caught mutation.
29. **For B2 (observability, not UI):** the `check_run` log line reported `sources_in_scope: 12` for a run whose cutoff preceded the new version's `version_time`, while the engine correctly did not read that version. The count probably filters on `source_time`, so the log overstates scope.
30. **Hinted form fields** use `<label for>` plus `aria-describedby`. The hint had been inside the label, so it became part of each field's accessible name. Found by the intake tests; the decision sheet's rationale field had the same flaw and is fixed.
31. **Edge is not executed.** `packages.microsoft.com` is refused by this container's proxy (403) and no Edge binary is present. Edge shares Chromium's engine (Blink), which is what the walk runs (Chromium 141), so the risk is low but unverified. Safari (WebKit) is untested for the same reason. Both need a person on a real machine; see the handoff.
32. **Mutation spot-checks, rounds 3 and 4, all applied and all caught** (then reverted):

    - fresh key sent each time;
    - namespace always sent;
    - title not locked when amending;
    - 415 text removed;
    - run control not re-keyed;
    - cutoff floored to the second;
    - cutoff floored to the minute (the old behaviour);
    - fractional seconds rejected.

### Found while @k verified the merge (same session)
33. **Regression shipped in the previous bundle, now fixed.** The "app-bar buttons do not wrap" polish (decision #32's commit) made the 375 px layout wider than the screen. The phone walk could then not close the source sheet.
    - How it slipped through: after that CSS change I re-ran `make test`, which does not include the browser walk.
    - Found while testing Node 26: it also failed on Node 22.
    - Fix: the rule is reverted. "Sign out" may wrap onto two lines on phones; that is cosmetic and on the B3.2 list.
    - Rule for B3 from now on: run the walk before every bundle.
34. **Node 25+ breaks jsdom storage in tests.** Node 25+ defines a global `localStorage`/`sessionStorage`, which is undefined unless `--localstorage-file` is given. Vitest 3.2.7 does not replace globals Node already defines, so every storage reference in a test resolves to Node's.
    - Reproduced on 26.9.0: all 24 cases failed at `tests/setup.ts` (`localStorage.clear()`).
    - The risk was not only noise. With a storage file configured, the "nothing stored in the browser" test would have checked Node's storage instead of the simulated browser's.
    - Fix: `vite.config.ts` passes `--no-experimental-webstorage` to test workers on Node ≥ 25.
    - Evidence: 24/24 on 22.22.2, 24.21.0 and 26.9.0; the storage mutation is still caught on 26; builds pass on 24 and 26; the walk is 10/10 on 22, 24 and 26.
35. **`engines` is now `^22 || ^24 || ^26`**, exactly the majors executed above; it was `>=22 <23`. The Makefile comment still says Node 22 and is integrator-owned, so B5's README should say "Node 22, 24 or 26".
36. **For @k (environment, not code):** lane folders made by copying another lane's folder carry state that does not move with the files.
    - `.venv` breaks, because console scripts hard-code the old interpreter path; `pytest` then cannot start.
    - `__pycache__` keeps the old lane's paths, so tracebacks show `.../B1/noteguard/...` in the B3 folder.
    - Prefer `git worktree add ../B4/noteguard -b b4-gov main` or a fresh clone per lane. In a copied folder, delete `.venv`, `__pycache__` directories and `frontend/node_modules`, then `make setup`.
